# 청약나침반 MVP — Render 배포용

## 포함 기능
- 접수기간 중·예정인 일반 아파트·무순위·불법행위 재공급 공고 조회 및 선택 지역 우선 정렬
- 공고 종류(기본값: 전체)와 지역·공급유형·주택 구분·분양가 상한·공급면적을 조합해 검색 (공급유형·분양가·면적은 동일 주택형 기준)
- 가상 제휴 매출 시뮬레이터
- 한국부동산원 청약홈 분양정보 API 연결
- 일반 아파트 공고의 청약홈 경쟁률 API 연결
- 공공데이터 API 인증키는 서버에서만 사용하며 카카오 지도 JavaScript 키만 브라우저에 전달
- 검색 결과 옆 카카오 지도와 공고별 주소 검색 링크 (내장 지도는 별도 키 설정 필요)

## 1) API 활용 신청
공공데이터포털에서 아래 두 API를 각각 활용 신청하세요.
1. https://www.data.go.kr/data/15098547/openapi.do
2. https://www.data.go.kr/data/15098905/openapi.do

개발계정은 무료이며 개발계정 신청은 자동승인으로 안내되어 있습니다. 실제 승인 상태는 로그인 후 마이페이지에서 확인하세요.

## 2) 로컬 실행
Node.js 18 이상이 필요합니다.

```bash
npm install
cp .env.example .env
```

`.env` 파일의 `DATA_GO_KR_SERVICE_KEY`에 공공데이터포털의 일반 인증키를 입력한 뒤:

```bash
npm start
```

브라우저에서 http://localhost:3000 을 여세요.

## 3) GitHub 업로드
압축을 풀고 프로젝트 폴더에서 GitHub 새 저장소를 만든 뒤 파일을 업로드하거나 다음 명령을 실행하세요.

```bash
git init
git add .
git commit -m "Initial CheongyakFit MVP"
git branch -M main
git remote add origin https://github.com/본인계정/저장소명.git
git push -u origin main
```

`.env`는 절대 업로드하지 마세요. `.gitignore`에 포함되어 있습니다.

## 4) Render 배포
1. https://render.com 에 로그인하고 New > Web Service 선택
2. GitHub 저장소 연결
3. Runtime: Node
4. Build Command: `npm ci`
5. Start Command: `npm start`
6. Environment Variables에 아래 항목 추가:
   - Key: `DATA_GO_KR_SERVICE_KEY`
   - Value: 공공데이터포털에서 발급받은 일반 인증키
   - `NODE_VERSION`: `22`
   - Instance Type: Free (무료 인스턴스는 유휴 시 중지될 수 있습니다.)
7. Deploy 클릭

배포가 끝나면 Render가 공개 URL을 제공합니다.

New > Blueprint에서 저장소를 연결하면 `render.yaml`의 설정을 사용할 수도 있습니다. `DATA_GO_KR_SERVICE_KEY`는 Render에서 직접 입력하세요. 저장소에 이 프로젝트 폴더 자체를 올리면 Root Directory는 비워 두고, 상위 폴더를 올리면 `cheongyakfit_render`로 지정하세요.

## 5) 카카오 지도 설정 (선택)

카카오 개발자 사이트 https://developers.kakao.com 에서 앱을 생성한 뒤, 앱 설정의 플랫폼 키에서 **JavaScript 키**를 확인하세요. REST API 키나 Admin 키가 아닙니다.

해당 JavaScript 키의 SDK 도메인에 `https://cheongyakfit.onrender.com`을 등록하세요. 로컬 테스트 시 `http://localhost:3000`도 등록합니다. 개발자 콘솔에서 카카오맵 사용 설정을 요구하면 활성화하세요.

Render 서비스의 Environment에 `KAKAO_MAPS_JAVASCRIPT_KEY`를 추가하고 JavaScript 키를 값으로 입력한 뒤 저장·재배포하세요. 로컬은 `.env`에 같은 이름으로 설정합니다. 기존 서비스에는 환경변수를 직접 추가하면 되며, 지도 키 없이도 공고 검색과 외부 카카오맵 주소 검색은 동작합니다.

이 키는 브라우저 SDK용 공개 키입니다. `/api/public-config`는 이 값만 전달하며 공공데이터 인증키·REST API 키·Admin 키는 노출하지 않습니다. 등록 도메인과 카카오 사용량·쿼터를 관리하세요.

‘검색 결과 지도 표시’ 또는 카드의 ‘지도에서 보기’를 누르면 SDK를 불러오고 공개된 공급주소만 카카오로 조회합니다. 개인 프로필은 전달하지 않습니다. 주소가 모호하거나 좌표 변환에 실패하면 임의의 위치를 표시하지 않습니다. 지도는 공급주소의 참고 위치이며 정확한 사업 부지 경계나 출입구를 보장하지 않습니다.

## 데이터 주의
- 분양정보 API: 일반 아파트(01), 무순위(04), 불법행위 재공급(06)의 공고 및 해당 주택형 조회
- 경쟁률 API: 일반 아파트 공고 전용. 무순위·불법행위 재공급의 경쟁률은 청약홈 공고 원문에서 확인해야 합니다.
- 경쟁률은 접수·은행 전산 상황 등에 따라 최종 청약홈 정보와 차이가 날 수 있습니다.
- 한국 날짜 기준으로 게시된 공고 중 전체 접수 종료일이 지나지 않은 공고를 표시합니다. 일반 아파트는 종료일 조건에 맞는 모든 페이지를, 무순위·불법행위 재공급은 전체 이력의 모든 페이지를 조회한 뒤 현재·예정 공고를 선별합니다. 데이터는 서버에서 최대 5분 캐시합니다.
- 주택형별 최고 분양가(만원), 공급면적(전용면적 아님), 제공된 공급유형별 배정 세대수를 사용합니다. 분양가 상한은 총 취득비용이나 대출 가능액을 뜻하지 않습니다.
- 공고 종류와 공급유형은 별개입니다. 전체 공급은 전체 접수기간, 특별공급은 특별공급 접수기간을 사용합니다. 일반공급은 일반 아파트의 지역·순위별 일정 또는 무순위·불법행위 재공급의 별도 일반공급 일정으로 확인하며, 전체 일정으로 대신하지 않습니다.
- 무순위·불법행위 재공급은 민영·국민 구분이나 일반공급 일정, 신혼부부·생애최초 등 특별공급 세부 배정이 제공되지 않을 수 있습니다. 특별공급 총 세대수를 세부 배정으로 간주하지 않으며, 필요한 자료가 누락됐거나 조회에 실패하면 ‘정보 확인 필요’ 그룹으로 분리합니다.
- 프로필의 혼인·자녀·생애최초 관심 응답은 관심 공급 추천에 사용합니다. 소득·자산 등은 공고문 확인 목록에만 반영하며 자격 판정이나 임의 제외에 사용하지 않습니다.
- 날짜 기준 상태이므로 실제 접수 시간과 공급유형·순위별 일정, 신청 자격은 공고 원문을 확인해야 합니다.
- 가상 매출은 시연용 숫자이며 실제 매출이나 제휴가 발생하지 않습니다.
